# Exchange-only SOEO–EO QEC research archive

**Status:** exploratory theoretical and numerical research; not peer reviewed, not a hardware demonstration, and not a validated QEC threshold.

This folder collects the singlet-sector detector, hybrid SOEO/EO interfaces, strict serial 13-pulse detector, Klein-four symmetry-averaged sequences, and the R146 exact-angle-family analysis.

See `manuscript/SOEO_EO_QEC_WORKING_PAPER.md` for the readable paper; numerical scripts, CSV pulse words, and supporting reports are under `reproduction/` and `source_reports/` when uploaded.

**Important:** Low-level SOEO total-spin detection is not the same as high-level logical $XXXX/ZZZZ$ stabilizer measurement. Model-only postselected fidelity is not decoded logical error. This repository is public; treat all results as an unreviewed research draft.
