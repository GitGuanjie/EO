## What is established?

A 13-pulse strict positive exchange measurement has an ideal seven-spin code residual near 2.19×10⁻¹⁵. Four representations generated by the SOEO Klein-four kernel have identical logical code action and distinct error-detection effects. In an ideal-readout persistent-gain model, four balanced cycles produce lower postselected logical-state infidelity than repeated fixed cycles at the same 52 exchange-pulse count. The precise assumptions, exclusions and literature-priority boundary are given in the paper.

## What is missing before a credible PRX submission?

Hardware timing and calibrated S/T readout/reset; a complete multi-SOEO/EO stabilizer check and decoder; unconditional logical-error-per-time benchmarks; independent finite-noise remeasurement on the desired geometry; a robust novelty comparison to existing exchange-only permutation decoupling; authorship/affiliation/AI disclosure and submission metadata.
