# EO — Exchange-Only Spin-Qubit Research

This repository contains exchange-only (EO) spin-qubit numerical control, robust gate compilation and stabilizer measurement research.

## Research collections

- **[Simultaneous exchange, CZ noise shaping and native QEC measurement (R138–R154)](research/eo-qec-2026/)** — working research manuscript, quantitative results ledger, reproducibility notes and full-precision example sequences.

The numerical studies are computational working results, not experimentally demonstrated hardware performance or fault-tolerant QEC thresholds. See the collection's [scientific caveats](research/eo-qec-2026/README.md) before citing.
